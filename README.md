# Проект: предсказание калорийности блюд

## Описание

Мультимодальная нейросеть для оценки калорийности блюд по фотографии, списку ингредиентов и массе порции. Модель объединяет текстовый и визуальный энкодеры с числовым признаком массы и предсказывает одно число - калорийность.

## Задача

Регрессия. Вход: изображение блюда (640x480, RGB), текст ингредиентов, масса в граммах. Выход: калорийность в ккал.

Датасет: 3262 блюда, из них после очистки 3259. Разделение train/test задано заранее (примерно 85/15).

Целевая метрика: MAE < 50 ккал на тестовой выборке.

## Архитектура

- Текстовый энкодер: DistilBERT (distilbert-base-uncased)
- Визуальный энкодер: ResNet18 (pretrained на ImageNet)
- Проекции текста, изображения и массы в общее пространство размерности 256
- Конкатенация трех проекций
- Регрессионная голова: Linear(768, 256) -> ReLU -> Dropout -> Linear(256, 1)

Масса нормализуется через log1p и стандартизацию по train.

## Структура проекта

- scripts/config.py - конфигурация (гиперпараметры, пути, модели)
- scripts/dataset.py - датасет, аугментации, DataLoader
- scripts/utils.py - модель, обучение, оценка, загрузка чекпоинта
- notebook.ipynb - EDA и запуск обучения
- checkpoints/ - артефакт обученной модели (не коммитится)
- data/ - датасет (не коммитится)

## Результаты

- Лучший val MAE: 34.59 ккал
- Test MAE: 39.40 ккал
- Требование MAE < 50 выполнено

Анализ ошибок показал, что модель точно предсказывает типичные низкокалорийные блюда (ошибка менее 1 ккал), но недооценивает высококалорийные блюда с редкими сочетаниями ингредиентов. Основные причины: длинный правый хвост распределения калорийности и отсутствие информации о количестве ингредиентов в текстовом описании.

## Запуск

1. Установить зависимости:

pip install albumentations timm transformers torchmetrics scikit-learn

2. Открыть ноутбук notebook.ipynb и выполнить ячейки сверху вниз.

3. Обучение воспроизводится вызовом:

cfg = Config()
model, mass_mean, mass_std, test_df = train(cfg, dish)

где dish - обработанный датафрейм из EDA.

## Воспроизводимость

Все источники случайности зафиксированы: SEED, cudnn.deterministic, worker_init_fn в DataLoader. Разбиение train/val детерминировано. Статистики массы считаются только по train и сохраняются в чекпоинт.

## Ограничения и направления улучшения

- Модель недооценивает блюда калорийностью выше 700 ккал
- Текст ингредиентов не содержит количества
- Маленькая val-выборка вызывает волатильность метрики между эпохами

Возможные улучшения: взвешивание лосса по калорийности, добавление массы ингредиентов в текст, oversampling высококалорийных блюд, увеличение val-выборки, кросс-модальное внимание.
